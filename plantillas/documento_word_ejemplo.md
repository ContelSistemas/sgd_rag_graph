# Manual de Procedimientos de Red

# 1. Descripción

Este documento describe los procedimientos estándar para la gestión de la red corporativa del SGD. Incluye configuración de VLANs, acceso a equipos y políticas de seguridad.

# 2. Configuración de VLANs

Las VLANs se configuran en los switches core y de acceso siguiendo el esquema de direccionamiento IP definido en la documentación de red.

VLAN 100: Gestión y administración de equipos de red.

VLAN 200: VoIP y telefonía IP.

VLAN 300: Datos de usuarios finales.

# 3. Acceso a equipos

El acceso a los equipos de red se realiza mediante SSH utilizando credenciales individuales. Se prohíbe el uso de cuentas compartidas.

# 4. Políticas de seguridad

Se debe aplicar el principio de menor privilegio. Los cambios en la configuración de red requieren aprobación previa y registro en el sistema de tickets.
